# PC Keyboard on the Device Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In Actions mode, a Keyboard button opens a full PC keyboard on the device that sends real key presses to the PC by scan code.

**Architecture:**
- The device runs a pure key-state machine that handles latch and lock modifiers and key repeat. It sends `keyboard.key` (sc, ext, down) actions.
- The PC injects scan codes with `SendInput`, tracks which keys are held, and releases all of them on close or at session end. The PC also tells the device which layout to draw: AZERTY or QWERTY.

**Tech Stack:** Python with ctypes `SendInput`; Kotlin and Compose with per-key multi-touch.

**Spec:** `docs/superpowers/specs/2026-10-19-keyboard-design.md`. Its §4 key table is exact data: use it verbatim. Branch `keyboard`.

### Task 2 — Android (model: sonnet)

Spec §2, §3 and §4 (labels).

- `keyboard/KeyLayouts.kt`: pure data for both layouts. Rows of keys with sc, ext, base/shift/altgr labels and relative width.
- `keyboard/KeyboardState.kt`: the pure automaton. It takes an injectable clock and emits `KeyEvent(sc, ext, down)` lists. Inputs: touch down, touch up, repeat tick.
- `keyboard/KeyboardActions.kt`: action JSON. `id` comes first, then the remaining keys in alphabetical order, as in the protocol doc.
- Parse the `keyboard` section in `ActionsState`.
- `ui/KeyboardScreen.kt`:
  - full screen over the tiles, with the context bar kept above and a ✕ button that sends `keyboard.release`;
  - per-key `pointerInput` so multi-touch works;
  - a repeat ticker;
  - haptics;
  - latch shown with a light fill, lock with a light fill plus a border.
- Header pill "Keyboard"/"Clavier" with the `ox_keyboard` icon in `ActionsScreen`. Strings go in `Strings` (en/fr).
- Tests: as listed in spec §6 (Android).
- Copy the debug APK to `dist/OrizonX-debug.apk`. Do not install.

**Commit:** `feat(android): full PC keyboard in Actions mode`.

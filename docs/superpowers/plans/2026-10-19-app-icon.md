# App Icon in the Context Bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the foreground app's icon (or the site's favicon) above its name in the Actions-mode context bar.

**Architecture:**
- The PC extracts the exe icon, or fetches the site favicon, in a background thread and caches it.
- `context.icon` carries the image's sha1, and the image itself goes over `MEDIA_ARTWORK`, once per session.
- Android keeps a 16-entry LRU of decoded images, shared by the cover art and the bar icon.

**Tech Stack:** Python 3.13 (ctypes Win32, PySide6 `QImage` loaded lazily, `urllib`); Kotlin and Compose.

**Spec:** `docs/superpowers/specs/2026-10-19-app-icon-design.md`. Branch `app-icon`.

### Task 1 — PC (model: sonnet)

Spec §2 and §3.
- `ForegroundApp.path`: the full exe path, with `compare=False`. The tracker fills it.
- `actions/app_icons.py` (`AppIconProvider`) does the exe-icon extraction and the favicon fetch, keeps the memory and disk caches, remembers failures, and runs its own worker thread. `icon_id(app, profile, url) -> str | None` never blocks, and `artwork_bytes(id) -> bytes | None` returns the image.
- `actions/context.py`: the snapshot gains `icon`.
- `actions/hub.py`:
  - sends each icon image once per session through `send_artwork`, alongside the `now_playing` cover;
  - asks the provider that produced the id for its `artwork_bytes`.
- `protocol/PROTOCOL.md`: document both changes above.
- Tests: those listed in spec §5 (PC), including one real, read-only conversion of `C:\Windows\System32\notepad.exe` to PNG (Qt test, skipped under `py`).

**Commit:** `feat(pc): app and site icon for the context bar`.

### Task 2 — Android (model: sonnet)

Spec §3 and §4.
- `UiModel`: replace the single `artwork` with an id → `ImageBitmap` LRU of 16 entries, decoded in the background (as today). Now-playing reads its id from it.
- `ContextBar.icon`, parsed tolerantly.
- `ContextBarStrip`: a 28 dp rounded icon above the app name when the image is present; the name alone otherwise.
- Tests: the LRU, `icon` parsing, and that the cover art still works.
- Copy the debug APK to `dist/OrizonX-debug.apk`. Do not install.

**Commit:** `feat(android): app icon above the app name in the context bar`.

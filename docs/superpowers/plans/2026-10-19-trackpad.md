# Trackpad on the Device Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Trackpad button in Actions mode that opens a large touchpad controlling the PC mouse, using Windows laptop gestures.

**Architecture:**
- The device recognises gestures with a pure state machine.
- It batches moves, scrolls and zooms into at most one message per 16 ms frame, sent as `trackpad.*` actions.
- The PC injects relative mouse moves, buttons, wheel/hwheel input and shortcuts with `SendInput`, and releases held buttons on close or stop.

**Tech Stack:** Python (ctypes `SendInput` with `MOUSEINPUT`); Kotlin and Compose (multi-pointer `pointerInput`).

**Spec:** `docs/superpowers/specs/2026-10-19-trackpad-design.md`. Branch `trackpad`.
